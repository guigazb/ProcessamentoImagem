Implementação de Operações aritméticas entre imagens, e entre uma imagem e um escalar

Requisitos: 
    - C++ instalado e configurado (caso não tenha, o executável contido no diretório já cria os arquivos de saída esperado)

para compilar: g++ -o AritmeticsEscalar Main.cpp / g++ -o AritmeticsImg OperacoesImg.cpp
para executar o código: ./AritmeticsEscalar.exe / ./AritmeticsImg.exe

o resultado está no mesmo diretório dos arquivos, denotado pelo nome.
